# Gradient Lab — CSS Gradient Generator

A beautiful, responsive CSS gradient generator made for the **MetaBox Internship Challenge — October 2026**.

## Features

- Two interactive colour pickers with editable hexadecimal colour values
- Gradient angle slider from **0° to 360°**
- Large, real-time gradient preview
- Generated CSS code and working **Copy** buttons with confirmation
- **Randomize** button
- **Stretch feature completed:** add or remove a third colour
- Bonus: five one-click gradient presets, swap colours, responsive mobile layout

## Tech

Pure HTML, CSS and JavaScript. No dependencies, backend, accounts, API keys, databases, or build step.

## Run locally

Download this repository and open **`index.html`** in a browser.

## Deploy to Vercel

1. Import the public GitHub repository into Vercel.
2. Set **Framework Preset** to **Other** (if needed).
3. Leave Root Directory as **`./`** (project root). No build command is needed.
4. Click **Deploy**.

## Manual test checklist

- [ ] Changing either colour updates the preview and CSS immediately.
- [ ] The angle slider moves between 0° and 360° and updates the gradient.
- [ ] Copying CSS shows a **Copied!** confirmation.
- [ ] Randomize changes the gradient.
- [ ] Adding a third colour includes it in the generated CSS; removing it goes back to two.
- [ ] Presets work, and the page is usable on mobile.

Developed with AI assistance as allowed by the challenge.
